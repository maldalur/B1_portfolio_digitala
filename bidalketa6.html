📋 Sarrera

Bidalketa honetan, ebaluazio formatiboa eta feedbacka emateko tresna digitalen erabilera aztertuko dugu. Atal honetan, bi ataza nagusi landuko dira: ebaluazio formatiboa (4.B) eta feedbacka (4.C). Prozesua hiru fase nagusitan banatzen da:

  • 1. Fasea: Aurre-ebaluazioa - Google Forms galdetegi baten bidez ikasleen hasierako ezagutza maila neurtu
  • 2. Fasea: Formakuntza eta ariketa praktikoak - edukiak eta ariketak entregatu
  • 3. Fasea: Ebaluazio formatiboa eta feedbacka - LLM aplikazioen bidez galdera zehatzagoak eta feedback pertsonalizatua

Chat guztiak eta balorazioak gordeta geldituko dira irakaslearen berrikuspenerako.

📊 1. Fasea: Aurre-ebaluazioa

Helburua: Ikasleen hasierako ezagutza maila neurtzea gaiaren inguruan, formakuntza hasi aurretik.

Tresnak: Google Forms galdetegi bat eta LLM aplikazio bat, oinarrizko kontzeptuak eta ezagutza maila aztertzeko.

  • Ariketen entrega egin

✅ Lorpen Adierazleak

  • ✓ Aurre-ebaluazioa: Bi tresna ezarri dira ikasleen hasierako ezagutza maila neurtzeko: Google Forms galdetegi estatikoa eta LLM aplikazio interaktiboa
  • ✓ Formakuntza: Aurreko bidalketetan (B1.1-B1.5) zehaztutako dinamikak, baliabideak eta jarduera interaktiboak integratu dira
  • ✓ Ebaluazio formatiboa: LLM aplikazio aurreratua diseinatu eta aplikatu da, ikasleen ezagutza mailaren eboluzioa neurtzeko galdera zehatzagoekin
  • ✓ Feedbacka: LLM baten bidez feedback pertsonalizatua emateko sistema bat ezarri da, ikaslearen eboluzioaren inguruko informazioa modu pertsonalizatuan emateko
  • ✓ Jarraipena: Chat guztiak eta balorazioak gordeta geldituko dira, irakasleari ikasleen eboluzioa eta parte-hartzea jarraitzeko aukera emanez
  • ✓ Tresna digitalen integrazioa: Google Forms eta bi LLM aplikazioen (aurre-ebaluazioa eta ebaluazio formatiboa) konbinazioak prozesu integral bat sortzen du, ikasleen gaitasun digitalak sustatuz

✓ Betetzen da: Bideoetan eta azalpenetan lorpen adierazle guztiak ageri dira eta praktikan erakusten dira, prozesu osoa fase bakoitzarekin.
